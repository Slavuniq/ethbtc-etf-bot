# План действий: сбор лидов «US-блогеры, лояльные к Лазурному берегу»

Дополняет `leads-french-riviera.md` (стратегия) и `riviera-seed-list.csv` (стартовые кандидаты).
Здесь — конкретные шаги, что автоматизируется, и кто за что отвечает.

---

## 0. Честная рамка (что реально, что нет)

- **Web-поиск даёт КАНДИДАТОВ, а не проверенный список.** Курируемые «топ-20» —
  в основном SEO. Каждого кандидата надо открыть и проверить по 2 критериям:
  (1) US-based / US-аудитория, (2) лояльность к Ривьере (не разовый пост).
- **Лайкеры и комментаторы по именам** официально недоступны (ни Graph API, ни Meta AI).
  Их собирают только сторонние скрейп-тулзы под твоим логином — это серая зона по ToS/GDPR.
- **Meta AI / Llama НЕ собирает лиды.** Это чат-LLM: помогает писать/классифицировать/
  скорить уже собранное, но не выгружает граф Instagram. Официальный discovery у Меты —
  это **Creator Marketplace** и **Graph API**, см. таблицу.

## 1. Seed-список блогеров (старт воронки)

См. `riviera-seed-list.csv`. Сейчас там ~14 кандидатов из открытого поиска, все со
статусом `VERIFY`. Это «затравка» (seed) для расширения через «похожих»/подписки.
Сильные кандидаты типа A (блогер-носитель): *Do You France?*, *Karin Dodson Gignoux*,
*Living on the Cote d'Azur*, *The American in Paris*, *Helene in Between*.
Хорошие источники аудитории (тип B): *Nice is Love*, *Riviera Love*,
*Experience the French Riviera*, *Riviera Go!*.

> Список НЕ финальный и НЕ проверенный по подписчикам/гео — это вход в воронку §3.

## 2. Что нужно сделать, чтобы собрать лиды (этапы)

1. **Доступы и тулзы** (раздобыть — это на тебе, см. колонку 3).
2. **Seed → расширение**: от эталонов идём по «похожим аккаунтам» и подпискам.
3. **Сбор кандидатов** по хэштегам/гео/запросам (хэштеги и boolean — в стратегии).
4. **Обогащение**: подтянуть bio, подписчиков, язык, страну аудитории.
5. **Сбор аудитории (тип B)**: комментаторы/лайкеры под Riviera-постами (только тулзой+логин).
6. **Квалификация и скоринг** по чек-листу (US? лояльность? ER? свежесть?).
7. **Дедуп + CRM**: единая таблица, метка A/B, контакт.
8. **Аутрич / ретаргет**: A — личные сообщения/коллаб; B — реклама/lookalike.

## 3. Разделение труда — кто что делает

| Шаг | Колонка 1 — **что Claude делает автоматически** | Колонка 2 — **что может AI/инструменты Meta** | Колонка 3 — **что можешь только ТЫ** |
|---|---|---|---|
| Seed-список | ✅ Уже собрал кандидатов web-поиском → CSV | Meta Creator Marketplace: фильтр креаторов по локации+стране аудитории (официальный discovery) | Дать доступ к Ads Manager/Creator Marketplace (бизнес-аккаунт) |
| Расширение «похожие/подписки» | ⚠️ Только если есть API/тулза с токеном — напишу скрипт | Meta AI: подсказать смежные ниши/хэштеги (идеи, не данные) | Залогиниться, прокликать «похожих» вручную там, где нет API |
| Сбор по хэштегам | ✅ Скрипт под Instagram Graph API (hashtag search) | Graph API сам по себе — это и есть Meta-инструмент (30 тегов/7д, 200 req/ч) | Завести IG Business/Creator + FB Page + получить токен |
| Сбор по локации/ключевым словам | ❌ В офиц. API нет поиска по гео/словам → нужен Apify/Phantombuster | — (Meta официально не даёт гео-поиск) | Оплатить/залогинить Apify или Phantombuster (сессия/cookies) |
| Лайкеры/комментаторы (тип B) | ❌ Не отдаёт ни API, ни я — только тулза под логином | ❌ Meta AI не выгружает; Ads даёт только агрегат-аудиторию | Решить по ToS/GDPR; запустить скрейп-актор под своей сессией |
| Обогащение (bio, подписчики) | ✅ Скрипт Business Discovery (публичные бизнес/креатор-аккаунты) | Graph API Business Discovery | Токен + бизнес-аккаунт |
| Проверка «US + лояльность» | ⚠️ Авто-эвристики (язык, гео-теги, частота) — черновой скоринг | Meta AI: классификация текста профиля (US-сигналы) | Финальная ручная верификация спорных профилей |
| Скоринг и CRM-таблица | ✅ Построю таблицу/CSV, формулы скоринга, дедуп | Meta AI: помочь ранжировать/тегировать список | Утвердить критерии и пороги |
| Аутрич тип A | ✅ Сгенерирую шаблоны DM/писем под сегмент | Meta AI: переписать/локализовать сообщения | Отправлять от лица бренда, вести переписку, закрывать коллабы |
| Ретаргет тип B | ✅ ТЗ на аудитории/креативы | **Meta Ads**: lookalike + interest «French Riviera» (это и есть применение Meta) | Запустить и оплатить рекламу в Ads Manager |

Легенда: ✅ делаю сейчас/скриптом · ⚠️ при наличии доступа/токена · ❌ принципиально не могу.

## 4. Где мне нужна помощь от тебя (минимум для старта)

1. **IG Business/Creator аккаунт + Facebook Page** и **токен Instagram Graph API** —
   тогда автоматизирую hashtag search и обогащение профилей.
2. **Аккаунт Apify или Phantombuster** (и согласие на их ToS-риски) — для гео/ключевого
   поиска и сбора аудитории (тип B), чего офиц. API не умеет.
3. *(Опционально, ускоряет в разы)* подписка **Modash / HypeAuditor / Heepsy** —
   фильтр «страна аудитории = US + тема France» закрывает поиск типа A почти целиком.
4. Доступ к **Meta Creator Marketplace** (бизнес-аккаунт) — официальный discovery.
5. Твоё решение по **легал/GDPR** для сбора аудитории и бюджет на тулзы/рекламу.
