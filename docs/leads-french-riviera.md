# Где искать лиды: американцы, лояльные к Лазурному берегу (Côte d'Azur)

> Предложение по источникам лидов. Профиль: **US-аудитория и US-блогеры**, которые
> регулярно показывают/продвигают **французскую Ривьеру** — Ниццу, Канны, Монако,
> Сен-Тропе, Антиб, Эз, Вильфранш, Ментон — а не «общие» travel-блогеры.

---

## 1. Профиль идеального лида (ICP)

Мы ищем не «любого блогера про путешествия», а того, кто одновременно:

1. **Базируется в США** (или вещает на US-аудиторию: язык — английский, валюта/цены в $,
   аудитория по гео — США).
2. **Лоялен к Лазурному берегу** — то есть Ривьера у него повторяется, а не разовый пост:
   - несколько постов/Reels/видео с геометками Nice / Cannes / Monaco / Saint-Tropez;
   - в highlights / плейлистах / закреплённых есть «French Riviera», «Côte d'Azur»;
   - в bio или контенте — «France-based American», «American in Nice», «expat», «Francophile».
3. **Имеет вовлечённую аудиторию** (живые комментарии и лайки — их тоже забираем как лиды).

Два подтипа лида:
- **A. Блогер-носитель** — сам американец/американка, показывает Ривьеру (наш «френчиз»).
- **B. Аудитория-носитель** — те, кто комментирует/лайкает посты с Côte d'Azur
  (потенциальные клиенты/подписчики, собираем из комментариев и лайков).

## 2. Где искать — по платформам

### Instagram (главный источник)
- **Геолокации (location tags)** — заходим в место и забираем «Recent»:
  Nice, France · Cannes · Monaco · Saint-Tropez · Antibes · Èze · Villefranche-sur-Mer ·
  Menton · Promenade des Anglais · Croisette · Monte-Carlo · Port de Nice.
- **Хэштеги** (см. §3) → вкладка «Reels» и «Recent» даёт самые свежие, а не вылизанный «Top».
- **«Похожие аккаунты»** — открываем 2–3 эталонных US-блогера по Ривьере и через
  стрелку «предложенные» собираем соседние аккаунты (граф похожих авторов).
- **Подписки эталонов** — смотрим, на кого подписаны сами «френчизы»: там кластер таких же.
- **Сбор аудитории**: под удачным постом с геометкой Côte d'Azur — список лайкнувших +
  комментаторы. Фильтруем по англоязычным/US-профилям.

### TikTok
- Поиск по хэштегам + по звукам/трендам, привязанным к Ривьере.
- Вкладка людей по запросам «american in france», «nice france», «cote d'azur».
- Комментарии под вирусными роликами про Монако/Канны — богатый источник US-аудитории.

### YouTube
- Запросы: «French Riviera travel», «living in Nice France», «Monaco vlog»,
  «Cote d'Azur American». Фильтр по каналам с английским языком/US-описанием.
- В разделе каналов — вкладка «Каналы» (рекомендованные) даёт соседей по нише.
- Комментаторы под видео = тёплая US-аудитория.

### Pinterest
- Очень «американская» площадка по travel-планированию. Доски «French Riviera»,
  «Cote d'Azur itinerary», «Nice France». Авторы досок — часто US travel-блогеры/планнеры.

### Блоги / сайты (Google)
- Travel-блоги с доменами .com, тон/орфография американские (color, traveler, vacation).
- Boolean-запросы — см. §4.

### Facebook-группы
- «Americans in France», «Expats on the French Riviera», «Living in Nice / Cannes»,
  «Côte d'Azur expats». Активные участники = и блогеры, и аудитория.

## 5. Инструменты для масштабирования

- **Influencer-базы / поиск:** Modash, HypeAuditor, Heepsy, Upfluence, Collabstr.
  Фильтры: страна аудитории = **US**, язык = EN, ключевые слова в bio = riviera/cote d'azur,
  локация контента = France. Это закрывает «US-блогер про Ривьеру» в один фильтр.
- **Гео/хэштег-парсинг:** Phantombuster, Apify (Instagram/TikTok/Google Maps scrapers) —
  для сбора авторов и **комментаторов/лайкеров** под постами с геометкой.
- **Анализ аудитории конкретного аккаунта:** проверка, что аудитория реально из США
  (а не накрутка/локальная французская).

---

## 6. Как квалифицировать лид (чек-лист)

| Критерий | Что проверяем |
|---|---|
| Гео автора | США / «US-facing» (язык, $, аудитория из США) |
| Лояльность к Ривьере | ≥ 3 постов/видео с Côte d'Azur, не разовый трип |
| Свежесть | активность за последние 1–3 месяца |
| Вовлечённость | живые комментарии/лайки (ER), не боты |
| Тип | A — блогер-носитель / B — аудитория из комментариев и лайков |
| Контакт | есть e-mail/«collab»/менеджер в bio (для A) |

Скоринг: гео+лояльность — обязательны; свежесть и ER — приоритизация.

---

## 7. Воронка сбора (пошагово)

1. Берём 5–10 **эталонных** US-аккаунтов про Ривьеру (seed).
2. Расширяем через «похожие» + «подписки эталонов» → кластер A-лидов.
3. По гео-меткам и хэштегам (§3) добираем свежих авторов.
4. Под топ-постами с геометкой Côte d'Azur снимаем **комментаторов и лайкеров** → B-лиды.
5. Прогоняем всех через чек-лист §6, маркируем A/B, складываем в таблицу/CRM.
6. По A — собираем контакты для аутрича; по B — ретаргет/контент.

---

## 8. Важно (легально и по ToS)

- Сбор лайкеров/комментаторов и парсинг — серая зона по **ToS платформ** и приватности
  (GDPR для EU-данных, CCPA для калифорнийцев). Для аутрича/рекламы по собранным контактам
  нужна правовая база и opt-out. Лучше: использовать публичные контакты из bio,
  официальные influencer-платформы и рекламные lookalike-аудитории вместо «сырого» скрейпа.
