# Протокол разбора видео

Цель — разложить чужой ролик на слои так, чтобы его можно было воспроизвести с нуля,
не имея исходников. Разбор одного ролика: 20–30 минут. Нужен плеер с покадровой
перемоткой (VLC: `E` — кадр вперёд) или DaVinci Resolve (бесплатной версии хватает).

---

Ключевая метрика для reels — **сохранения и репосты**, не лайки. Если их видно —
именно они показывают, какой формат тиражируется.

---

## B. Хук (первые 0–3 секунды)

Разбирается отдельно, потому что решает 80% результата.

- **Первый кадр** (стоп-кадр на 00:00): что в нём, есть ли лицо, есть ли текст, есть ли движение.
- **Первые произнесённые слова** — выписать дословно.
- **Текст на экране в первые 2 сек** — дословно.
- **Тип хука:**
  - вопрос к зрителю («а вы знали, что…»)
  - обещание результата («покажу, как за 10 минут…»)
  - конфликт / провокация («все делают это неправильно»)
  - визуальный шок (необычный кадр, невозможная физика — сильная сторона AI-видео)
  - недосказанность / открытая петля («досмотрите до конца, там…»)
  - разрыв шаблона (кадр не соответствует звуку)
- **Когда появляется первая склейка** — если позже 2 сек, это осознанный «дыхательный» хук;
  если раньше 1 сек — клиповый.

## C. Покадровая раскадровка

Главная таблица разбора. Строка = один план (между склейками).

| # | Тайминг | Длит. | Что в кадре | Крупность | Движение камеры | Реплика | Текст на экране | Звук/SFX |
|---|---|---|---|---|---|---|---|---|
| 1 | 0:00–0:02 | 2.0 | | КП | статика | | | |
| 2 | | | | | | | | |

**Крупность:** ДП (деталь), КП (крупный), СП (средний), ОП (общий), ДОП (дальний общий).
**Движение:** статика, наезд/отъезд (push in/out), проводка (pan), тревеллинг, орбита, ручная камера.

Из таблицы автоматически считаются:

- **ASL (average shot length)** = длительность / число планов. Ориентиры: reels-клиповый монтаж
  1.0–1.8 с; повествовательный 2.5–4 с; «фильмовый» 4–8 с.
- **Профиль ритма**: где планы короче (нагнетание) и где длиннее (выдох, смысловая точка).
- **Число уникальных генераций** — сколько раз пришлось бы сгенерировать клип.

## D. Визуальный слой: снято или сгенерировано

### D1. Природа кадра

Для каждого плана поставить метку: `реальная съёмка` / `AI-генерация` / `гибрид`
(реальная съёмка + AI-фон, AI-объект, замена лица) / `стилл + оживление` (image-to-video) /
`графика / скринкаст`.

### D2. Признаки AI-генерации (проверять на стоп-кадре и в замедлении 0.25x)

Сильные признаки:
- **Кисти рук и пальцы** — лишние/слипшиеся фаланги, «резиновое» сгибание.
- **Текст в кадре** — вывески, обложки книг, надписи на одежде: псевдобуквы.
- **Мелкие повторяющиеся объекты** — толпа, листва, узоры: морфинг между кадрами.
- **Украшения, зубы, ногти** — плывут или меняют количество.
- **Взаимодействие с предметами** — предмет проходит сквозь руку, чашка меняет форму.
- **Фон при движении камеры** — «дышит», объекты появляются/исчезают.
- **Волосы и очки** — контур подрагивает.

Слабые (но диагностичные) признаки:
- Слишком идеальный свет и кожа при отсутствии съёмочной команды.
- Отсутствие настоящей глубины резкости — фон размыт равномерно, а не по расстоянию.
- Длина плана строго ≤ 5, 8 или 10 секунд — прямое следствие лимитов генераторов.
- Абсолютно неподвижная камера или, наоборот, идеально плавная орбита без микродрожи.

### D3. Фингерпринт модели (гипотеза, не факт)

Определение модели по кадру — всегда вероятностное. Ориентиры на сентябрь 2026:

| Признак в кадре | Вероятный источник |
|---|---|
| Речь и SFX сгенерированы вместе с картинкой, губы точно попадают, звук «комнатный» | Veo 3.x (нативное аудио) |
| Очень естественная физика человеческого движения, танцы, спорт, длинные планы | Kling 3.x |
| Сильное следование сложному промпту, точная композиция, режиссёрский контроль | Runway Gen-4.x |
| Выраженный «киношный» look, эффектная, но слегка условная физика | Sora 2 (модель снята с поддержки в 2026 — если ролик свежий, скорее нет) |
| Идеально стабильное лицо через много планов | Работа от стиллов (image-to-video) или LoRA, а не text-to-video |
| Говорящая голова с идеальным липсинком, но «мёртвым» телом | Аватар-платформа (HeyGen/Synthesia-класс) |
| Оживление одной фотографии, лёгкий параллакс | image-to-video / Higgsfield-класс пресеты |

**Практический вывод важнее названия модели:** если лицо стабильно между планами —
значит, работа идёт от заранее сгенерированных изображений. Это главный
воспроизводимый приём, и его надо забирать в свой пайплайн.

### D4. Обработка

- Цветокоррекция: единый LUT? тёплая/холодная схема? крашенные тени?
- Зерно/шум, виньетка, лёгкий блик — добавлены ли поверх генерации (маскируют AI-артефакты).
- Апскейл: видны ли следы (перешарп, «пластик») → Topaz-класс.
- Кроп: генерация в 16:9 с последующим кропом в 9:16 (видно по «тесной» композиции)
  или нативная вертикаль.
- Скорость: замедления/ускорения, интерполяция кадров.

## E. Аудио слой

- **Голос:** живой / клонированный / синтезированный. Признаки синтеза: ровное дыхание
  или его отсутствие, одинаковая энергия к концу фразы, нехарактерные ударения в редких словах,
  отсутствие призвуков губ. Клонированный голос звучит как автор, но «слишком чисто».
- **Язык и акцент**, темп речи (слов/мин), паузы.
- **Музыка:** трендовый трек / сгенерированная / библиотечная. Есть ли ducking под голос.
- **SFX и фоли:** шаги, ткань, окружение — добавлены вручную или нативные из генератора.
- **Тишина как приём:** есть ли обрывы звука под акцент.
- **Громкостная драматургия:** нарастает ли к концу.

---

## F. Текст и графика

- Шрифт (гарнитура, насыщенность), размер, цвет, обводка/подложка.
- Позиция: верх / центр / низ (низ часто перекрывается UI — если текст внизу, автор
  не оптимизировал под интерфейс).
- Субтитры: пословные (karaoke), пофразовые, отсутствуют.
- Кинетика: появление буквами, скейл-поп, тряска на акцентах.
- Брендинг: логотип, ник, единая плашка — есть ли постоянный элемент во всех роликах.

---

## G. Монтаж

- ASL (из таблицы C).
- Типы склеек: прямая, match cut, J/L-cut (звук уходит вперёд картинки), whip pan,
  склейка на движении, morph/transition-эффект.
- Синхронизация с битом: попадают ли склейки на доли.
- Наличие «дыхания» — планов длиннее 4 сек в середине.

---

## H. Смысловой слой

- Тема и ниша ролика.
- Целевая аудитория, её боль.
- Оффер: что обещано зрителю.
- Роль ролика в воронке: охват / прогрев / продажа / соцдоказательство.
- CTA: явный или скрытый, где именно (в кадре / в подписи / в закрепе).
- Есть ли петля на следующий ролик (серийность).

## I. Реверс-инжиниринг: гипотеза пайплайна

Расписать шагами так, как это делал бы автор:

```
1. Сценарий: ~N слов, ~M сек речи
2. Стиллы: K изображений (модель, стиль)
3. Генерация: P клипов по X сек (модель)
4. Голос: способ
5. Липсинк: нужен / не нужен
6. Музыка: источник
7. Сборка: редактор, субтитры
8. Постобработка: LUT, зерно, апскейл
```

| Оценка | Значение |
|---|---|
| Число генераций (с учётом брака ×3–5) | |
| Время производства | |
| Стоимость (кредиты/подписки) | |
| Уровень сложности | низкий / средний / высокий |

## J. Выводы по ролику

- **Что работает и забираем:** 3–5 пунктов.
- **Что слабо и делаем лучше:** 3–5 пунктов.
- **Что нельзя копировать** (личность, лицо, голос, фирстиль).

---

## Сводка по всем роликам (`analysis/_SUMMARY.md`)

После 10+ карточек свести:

- Медианная длительность и ASL.
- Доля роликов с говорящей головой.
- Повторяющаяся структура (например: хук 2 с → проблема 4 с → 3 шага по 6 с → CTA 3 с).
- Постоянные визуальные константы: палитра, шрифт, крупность первого кадра.
- Постоянные звуковые константы.
- Тип хука, встречающийся чаще всего.
- **Формула аккаунта** — одно предложение, из которого делается собственный шаблон.
