# Разбор видео-методики @manokhina_ai и производство собственного «фильма»

## Статус доступа

Аккаунт `instagram.com/manokhina_ai` в этой рабочей среде **недоступен**: весь исходящий
трафик идёт через egress-прокси организации, и домен `www.instagram.com` им заблокирован
(`EGRESS_BLOCKED`). Это политика доступа, а не техническая ошибка, поэтому обходить её
я не стал. Через веб-поиск публичных перепечаток контента этого аккаунта тоже нет.

**Следствие:** покадрового разбора *конкретных* её роликов здесь нет — он появится, как
только материал попадёт в работу (см. «Что нужно от вас»).

**Что сделано вместо ожидания:** собран весь каркас, который не зависит от доступа —
протокол разбора (по нему любой ролик раскладывается на слои за 20–30 минут),
методика производства фильма и библиотека промптов. Когда придут файлы, работа
сводится к заполнению карточек, а не к изобретению метода.

## Что нужно от вас

Любой из вариантов, по убыванию полезности:

1. **Файлы роликов** (5–15 штук, самых показательных) — скачать через любой downloader
   и положить в чат/репозиторий. Идеально: `.mp4` в оригинальном качестве.
2. **Скринкаст пролистывания профиля** + отдельные записи 3–5 роликов целиком со звуком.
3. **Скриншоты**: сетка профиля, шапка, первые кадры роликов, подписи, статистика (если есть).
4. **Текстом**: о чём аккаунт, кто в кадре (реальный человек / AI-персонаж), длина роликов,
   есть ли говорящая голова, есть ли субтитры, что продаёт.

Минимально рабочий вход — пункт 4 плюс 3–4 скриншота первых кадров.

## Структура

| Файл | Назначение |
|---|---|
| `01-analysis-protocol.md` | Протокол разбора одного ролика: что фиксировать, как определить модель-генератор по артефактам, как считать метрики монтажа |
| `02-production-pipeline.md` | Методика создания видео в формате фильма: от логлайна до мастера, с бюджетом и таймингом |
| `03-prompt-templates.md` | Шаблоны промптов: шот, character sheet, локации, звук, негативы |
| `analysis/_TEMPLATE.md` | Пустая карточка разбора — по одной на ролик |

## Порядок работы

1. Собрать 10–15 роликов → на каждый завести `analysis/NN-краткое-имя.md` из шаблона.
2. Заполнить карточки → свести общие паттерны в `analysis/_SUMMARY.md`
   (что повторяется в 80% роликов — это и есть её формула).
3. Формулу перенести на длинный формат по `02-production-pipeline.md`.

## Правовая рамка

Разбирать и воспроизводить **методику** (структура, темп, приёмы монтажа, тип промптов) —
нормально, это ремесло. Не воспроизводим: лицо и голос конкретного человека, узнаваемый
логотип/фирстиль, дословные сценарии, чужие исходники. Персонажа делаем своего.
